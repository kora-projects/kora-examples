# Kora JSON

Runnable regression example for compile-time Kora JSON codecs.

Covered cases: `@Json`, `@JsonReader`, `@JsonWriter`, required and nullable fields,
`@JsonField`, `@JsonSkip`, `@JsonInclude`, `JsonNullable`, collections, maps, time
types, `RawJson`, enums with a custom JSON value, sealed and generic sealed types,
and a field-specific manual codec selected with `@Mapping`.
